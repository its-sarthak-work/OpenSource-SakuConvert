# SakuConvert Privacy Model

## Normal conversion

Image and video conversion run locally on the device.

## Online background removal

This is a separate, explicit exception. The user must confirm before an image is uploaded.

SakuConvert displays the remaining daily allowance and warns that the image will be sent to the selected third-party provider.

The provider's server-side limit is authoritative. The local counter exists for clear user feedback and is not presented as a cryptographic guarantee.

## UI privacy center

The Help → Privacy Center explains local processing, online features, files and temporary data, and network transparency.
