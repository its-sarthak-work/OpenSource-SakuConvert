# Supported Formats Roadmap

Initial target categories:

- Images: JPG/JPEG, PNG, WebP, GIF, BMP, TIFF, SVG, ICO, HEIC/HEIF, AVIF
- Video: MP4, MKV, MOV, AVI, WebM, FLV, WMV, M4V, MPEG
- Audio: MP3, WAV, FLAC, AAC, M4A, OGG, OPUS, WMA
- Documents: PDF, DOC, DOCX, TXT, RTF, ODT
- Office: XLS, XLSX, CSV, ODS, PPT, PPTX, ODP
- Archives: ZIP, 7Z, TAR, GZ, BZ2, XZ
- Subtitles: SRT, VTT, ASS, SSA

Format support will be added incrementally and only marked supported after real conversion and validation tests.


### Documents
- PDF → Word (DOCX)
- Word (DOCX) → PDF
- Image → Text (OCR)
- Text → PNG image
